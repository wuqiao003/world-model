## 2. 否决的方案（本日新增）

1. **用「全序列 negate」测 memory↔controllability** — 记忆也吃到反事实动作，隔离失败。  
2. **用 `self_cf_gap` 单独当 Excitation 主指标** — demo 在 OOD 上会「爆炸式敏感」，看起来像更可控，实际是外推失稳。  
3. **经代理 git clone TRELLIS** — 继续否决；改用 CFS + `trellis2` conda。  
4. **在无头容器里直接 `import open3d`** — 易挂起；需 stub 或 headless 配置。  
5. **hjm `trellis2` env 跑 TRELLIS v1** — 缺 kaolin；改用 `/mnt/group/lzdql/miniconda3/envs/m3d-trellis`。  
6. **Sel-Mem v1** — 「只在 event 写」并不自动优于 always；需更强稀有事件 + 覆盖代价，或对 write head 加监督。

## 3. 保留并强化的主张

- **CAF**：必须同时看「动作是否改变预测」+「反事实是否对齐 oracle」（`caf = self_gap / pv`）。  
- **Mem–Ctrl**：必须用 **frozen-memory + 仅翻转当前动作**。Mem v3：`w∈{0,0.25,0.5,0.75,1}` → instant gaps `≈0.0013, 0.00049, 0.00028, 0.00045, 0`。  
- **Excitation**：高激励数据提升 **高激励评测上的 predictive validity**，不是抬高 self-gap。
